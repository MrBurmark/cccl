<cuda/std/linalg>

Provided functionalities

  • scaled() std::linalg::scaled

  • scaled_accessor std::linalg::scaled_accessor

  • conjugated() std::linalg::conjugated

  • conjugated_accessor std::linalg::conjugated_accessor

  • transposed() std::linalg::transposed

  • layout_transpose std::linalg::layout_transpose

  • conjugate_transposed() std::linalg::conjugate_transposed

Extensions

  • C++26 std::linalg accessors, transposed layout, and related functions are available in C++17

Omissions

  • Currently we do not expose any BLAS functions and layouts.

Restrictions

  • On device no exceptions are thrown in case of a bad access.

  • MSVC is only supported with C++20
