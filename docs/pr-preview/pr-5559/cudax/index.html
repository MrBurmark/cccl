CUDA Experimental

CUDA Experimental (cudax) provides experimental new features that are still in development and subject to change. However, any feature within this library has important use cases and we encourage users to experiment with them.

Specifically, cudax provides:

  • uninitialized storage

  • an owning type erased memory resource

  • stream-ordered memory resources

  • graph functionality

  • dimensions description functionality

  • an implementation of the STF (Sequential Task Flow) programming model

Stability Guarantees

There are no stability guarantees whatsoever. We reserve the right to change both the ABI and the API of any feature within cudax at any time without notice.

Availability

Due to its experimental nature and the lack of stability guarantees, cudax is not shipped with the CUDA toolkit but is solely available through github.
