cuda::experimental::graph

Defined in include/cuda/experimental/__graph/graph.cuh

struct graph

An owning wrapper for a cudaGraphExec_t handle.

The graph class provides a safe and convenient interface for managing the lifecycle of a cudaGraphExec_t object, ensuring proper cleanup and resource management. It supports move semantics, resource release, and launch of the CUDA graph.

See also

cuda::experimental::graph_builder

Note

The graph object is not directly constructible. One is obtained by calling the instantiate() method on a graph_builder object.
