cuda::experimental::stf::instance_id_t

Defined in include/cuda/experimental/__stf/places/places.cuh

enum class cuda::experimental::stf::instance_id_t : size_t

ID of a data instance.

A logical data can have multiple instances in various parts of memory (CPU and several GPUs). This type identifies the index of such an instance in the internal data structures.

Values:

enumerator invalid
